# My Drive — Google Drive-Style Interface

A clean, responsive file storage interface built with HTML, CSS, and JavaScript.

---

## 📁 Project Files
| File | Purpose |
|---|---|
| `index.html` | Main page structure and interactivity |
| `style.css` | All styling and responsive layout rules |
| `README.md` | Project instructions and information |

---

## 🚀 How to Use
1. **Save all files** in the same folder:
   - Copy the HTML code → save as `index.html`
   - Copy the CSS code → save as `style.css`
   - Copy this text → save as `README.md`
2. **Open the app**:
   - Double-click `index.html`
   - It will load in your default web browser
3. **No internet or setup needed** — it works fully offline

---

## ✨ Features
- 🔍 **Search** — type to instantly filter folders by name
- 📂 **Browse folders** — click any folder to view its contents
- ← **Back button** — return to home view at any time
- ＋ **New menu** — click to see file/folder creation options
- 📱 **Mobile-friendly** — adapts to phones and tablets
- 🎨 **Modern design** — matches Google Drive look and feel
- ⭐ **Navigation** — sidebar highlights active section

## 🛠️ How It Works
- **HTML** — defines the page layout and content
- **CSS** — controls colours, spacing, and responsive design
- **JavaScript** — powers search, folder switching, and interactive menus

---

## 📝 Customisation Ideas
- Add your own folder names or files in the `folderContents` list inside `<script>` in `index.html`
- Change colours in `style.css` (look for hex codes like `#4285f4`)
- Add more folders by copying the `.folder` block in the HTML

---

## ⚠️ Troubleshooting
- **Page looks plain?** Make sure `style.css` is in the same folder as `index.html`
- **Links not working?** Check the `<link rel="stylesheet" href="style.css">` line is correct in the HTML `<head>`
- **Best viewed** in Chrome, Firefox, Safari, or Edge (modern browsers)
